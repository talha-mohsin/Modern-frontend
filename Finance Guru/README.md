# Finance Guru

My first project built with **React** and **Tailwind CSS** — **Finance Guru** is a modern landing page created to practice component-based development and clean UI design.

The project uses **reusable components** and **props** to manage data efficiently, while **Tailwind CSS** provides a responsive and visually appealing layout.

It includes key landing page sections such as:

- Hero Section
- Features
- Testimonials
- Call to Action

This project demonstrates modern front-end development practices and a structured approach to building scalable **React applications**.

## Technologies Used
- React
- Tailwind CSS
- JavaScript
- HTML5

## Purpose
To learn and apply React fundamentals like components, props, and modern UI styling using Tailwind CSS.
